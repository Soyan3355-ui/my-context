# プロジェクト指示（「ゲーム作成」プロジェクト用）

このプロジェクトでは、ブラウザで遊べるゲームを作ります。
過去作「封札モンスターズ」の開発キットを、プロジェクトのナレッジとして登録しています。

## 必ず守ること

1. 作業を始める前に、ナレッジの「02_開発ガイド.md」を読む
2. ドット絵を描くときは「03_ドット絵の品質基準_PIXMON_STYLE.md」に従う
   - 描画には「04_pixkit.js」を使い、「05_pixmon_1_基準の6体.js」の書き方を手本にする
   - 品質の目安は「06〜08」の見本画像。これと同じ密度・陰影・輪郭を目指す
3. 既存ゲームのキャラクターに似たデザインは作らない。テイストだけを参考にする

## 進め方

1. まず絵柄の見本（キャラ3体と画面1枚）だけを作り、見本画像と比べて足りない点を直してから見せる
2. OKが出たら、最初から最後まで遊べる最小版を作る
3. 作る → テスト → レビュー → 修正 を最低2周する
4. 数値（難しさ、経験値、確率など）は1つのファイルにまとめる。難しさは「推奨レベル」と「勝率」で決め、計算で確かめる
5. 取り返しのつかない操作は二重確認にし、初期選択を「やめる」にする
6. 報告は「変えたこと」「確認したこと」「未確認のこと」に分ける

## 技術の方針

- 素のHTMLとJavaScriptだけで作る。ファイルを開くだけで動くようにする
- 画像や音のファイルは使わず、ドット絵・BGM・効果音はコードで作る
- スマホとPCの両方で操作でき、画面が崩れないようにする
