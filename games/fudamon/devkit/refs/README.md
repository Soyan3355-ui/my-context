# 参考画像の置き場所

著作物のため、参考画像はリポジトリに含めていません。品質比較をするときは、以下のファイル名で画像をこのフォルダに置いてください。

| ファイル名 | 内容 |
|---|---|
| 2.png | SFC版ドラクエのモンスタースプライト一覧（ボス・悪魔系） |
| 3.png | SFC版ドラクエのモンスタースプライト一覧（混合） |

| 5.webp | 公式イラスト集の表紙（愛嬌と個性の参考） |

画像がなくても `compare.html` は自作スプライトだけを表示して動きます。新しい参考画像を使う場合は、`compare.html` の `REF` 表に切り抜き座標を追加してください。
