# 新サイト ページ構成（サイトマップ）案 v0.1

- 作成日: 2026-10-10
- 状態: たたき台（オーナー確認前）
- 根拠: `standards/website-standard.md` 第1・2・5・7章、`reports/website-inventory-2026-10-01.md`

## 1. 設計の考え方

1. **目的は講座の申込を増やすこと。** どのページからも、2クリック以内で講座の申込に着けるようにする。
2. **初心者が安心できる材料を、講座ごとのLPに集める。** 当日の流れ、持ち物、参加者の声、よくある質問を、申込の直前に読める位置に置く。
3. **講座の入口を記事から固定ページに戻す。** 現行サイトは「畑の寺子屋」などの入口が記事（`/posts/{ID}`）になっており、構造が分かりにくい。
4. **現在の募集を一番目立たせる。** 終了・満席の講座は、一覧の下に「終了」と明示して残す。
5. **読み物（記事）は、農的暮らしの入口とSEOの受け皿にする。** 直近2〜3年分を移行し、それ以前は301リダイレクトで転送する。

## 4. 旧URLとの対応

| 旧URL | 対応 |
|---|---|
| `/` | `/`（同じ） |
| `/pages/1561015/page_201801111648`（私たちについて） | 301 → `/about/` |
| `/pages/1628266/page_201802041018`（お問い合わせ） | 301 → `/contact/` |
| `/pages/7244115/page_202309051202`（出張サービス） | 301 → `/services/` |
| `/posts/59175356`（畑の寺子屋について） | 同URLを維持。ページ上部に `/terakoya/` への案内を置く（または301。決定事項） |
| `/posts/58707134`（お米づくり道場について） | 同URLを維持。ページ上部に `/rice/` への案内を置く（または301。決定事項） |
| 移行する記事（直近2〜3年分） | `/posts/{ID}` のまま再現 |
| 移行しない記事 | 301 → 関連する講座ページ、なければ `/posts/` |
| 月別アーカイブ `/posts/archives/{年}/{月}` | 新サイトで自動生成、または 301 → `/posts/` |

外す前に、Search Consoleで検索流入の多い記事がないかを確認する（1週間分のデータが取れ次第）。

## 5. 制作の優先順位（案）

1. トップ、講座LP 2本（フィールドデザインカレッジ、基礎講座）。募集の成果に直結するため。
2. `/terakoya/`、`/rice/`、`/courses/`、`/faq/`。
3. お知らせ（Notion連携）、読みもの（記事移行）、`/about/`、`/contact/`、`/services/`。
4. `/voices/`、法的ページ、リダイレクト設定。

## 6. オーナーに決めてほしいこと

1. **講座の入口は4つ並列でよいか。** 初心者向けに「まずはここから」の1本を作るか。
2. **旧 `/posts/59175356` と `/posts/58707134` は、残す／301で新LPへ転送のどちらにするか。** 検索流入がある可能性があるため、Search Consoleを見てから決めるのが安全。
3. **参加者の声のページ（`/voices/`）を独立させるか。** 声の素材がどれだけあるかによる。
4. **YouTube専用ページを作るか。** 当面はトップとフッターの導線のみで足りるか。
5. **申込・決済サービス。** 現状はGoogleフォームとcoeteco。LPの申込ボタンの遷移先と、特定商取引法の表記の要否に影響する。
6. **グローバルナビの表示名。** 「講座をさがす」「読みもの」などの言い回しは、トーン（ていねいで落ち着いた暮らし系）に合っているか。
