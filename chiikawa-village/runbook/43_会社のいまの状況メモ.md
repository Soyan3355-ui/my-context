## 会社のいまの状況メモ（社内チャットの記憶。2026-10-02 そーやん「同じ話を何度もしたくない」）

- 社内チャットは1つの部屋（だれに聞いても会話がつながる）。アスカ（宇宙からの相棒・関西弁）もキャラとして登場し、チャットの最初の相手
- チャットの返事は「じっくり考える」（modelTier complex）が初期値。毎回、次を読んでから答える：
  - 共有 `brief/now`（`{text, updatedAt, by}`）：会社のこと・方針・予定・最近できたこと・返事待ち。お金の中身・家族・個人の誕生日などは書かない
  - そーやんだけ `data/users/<id>/brief`（ArtifactData では collection `data/users/me`、doc `brief`）：お金・人事部・こころの記録の要点
  - 決定記録（直近15件）・つぶやき（直近6件）・ボード・そーやんの仕事・判断待ちのカード
- 更新するのはアスカ（見回りの回と、Claude Code でそーやんと話したとき）：
  1. Claude Code の会話で決まったこと・わかったことは、その場で `brief/now`（共有してよいもの）か `data/users/me/brief`（お金・人のこと）に反映する
  2. 見回りの回で `data/users/me/chat`（画面の社内チャットの記録）を読み、決まったこと・頼まれたことを拾ってタスク・カード・brief に反映する（同じことをそーやんにもう一度聞かない）
  3. brief は全体で 6000 字ほどまでに保ち、古くなった予定や片付いたことは消す
