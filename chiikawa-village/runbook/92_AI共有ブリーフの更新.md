## AI共有ブリーフの更新（2026-11-07 そーやんの依頼：ChatGPT・Muse など他のAIが、最新の状況を踏まえて答えられるように）

Claude Code の朝・夕の回が、**最後の仕事として**Google ドキュメント「AI共有ブリーフ（ちいかわ株式会社の最新状況）」を上書きする。他のAIはこれを読んで（またはそーやんが貼って）状況を知る。

- 場所：Google ドキュメント ID `1jabHcmq-wUea_cqxGVHRUyssJvMVRmRjudOUqr9ZSrg`
- 書く元：その回で更新した `brief/now`・`status/now`・進捗ログの「次の回へ」。**新しく調べ直さない**（トークンを使わないため）
- やり方：Google_Docs の read_doc で末尾の位置を確かめ、本文を全部消して（deleteContentRange）、新しい本文を insertText で入れる。1回の update_doc で済ませる
- 1500字までに収める。項目は雛形のとおり：更新日時（日本時間）／進行中の仕事（最大7件。名前・状態・次の一手・期限）／今日・今週の予定と期限（最大7件）／そーやんの判断待ち（最大5件）／直近の決定事項（最大5件・日付つき）／他のAIに頼むと良いこと・頼まないこと
- **載せないもの**：お金の金額、受講生の名前・連絡先、パスワード・トークン類、`data/users/me/brief` の中身。迷ったら載せない
- 前回から変化がなければ書き換えない（更新日時だけ変えない）
- 失敗しても本編は止めない。進捗ログに1行「ブリーフ更新失敗：原因」と残す
