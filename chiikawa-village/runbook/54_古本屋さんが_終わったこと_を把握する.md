## 古本屋さんが「終わったこと」を把握する（2026-10-02 そーやんの指摘：すでに完了にしたことを、古本屋さんが把握できていない）
- 原因：進行表（`timeline/now`）は見回りのときだけ更新されるので、そーやんが画面で完了にしたこと・決めたことが、次の見回りまで反映されない。
- 画面側（済み）：①古本屋さんとの会話に、直近14日で「終わらせた仕事・完了したボード・決めた判断カード・終わったと答えたプロジェクト」を「いちばん新しい事実」として渡す。進行表と食い違うときは、こちらを優先し、「終わっているよね、直しておくね」と受け止める。②「きょうのお願い」の古本屋さんの声かけに「もう終わってる」がある。押すと、画面の進行表を一時的に完了に直し、つぶやき箱に古本屋さん宛のお願い（`request:true`、`to:'kani'`）を出す。
- 見回りの仕事（朝・夕。古本屋さんが `timeline/now` を更新する前に必ず）：
  1. 突き合わせる：①`tasks`（共有）で `done:true` になったもの（`doneAt` が前回の更新より新しい）、②`board` の `status:'done'`、③`exceptions` の回答済み（`answeredAt`）と `decisions`、④`notes` の `request:true` のうち、`to:'kani'` で「もう終わっています」を含むもの（プロジェクト名か「マイルストーン名（日付）」が書いてある）、⑤Notion の ✅タスク・タスクボードで完了のもの。
  2. 該当する `projects[]` の項目を直す：全部済んだプロジェクトは `status:'done'`・`progress:100`。マイルストーンは `done:true`。`next` は次にやることに書き換える（済んだことを書かない）。
  3. 直したら、その `notes` に返事を付け（「進行表を直しました」）、`handled:true` にする。
  4. `timeline/now.updatedAt` を更新する（画面は、更新時刻が新しくなると、そーやんの一時的な「終わってる」を外す）。
  5. `pmNote`（今週の見立て）に、すでに終わったことを「これから」として書かない。
- 迷うとき（完了の証拠が弱い・複数の記録で食い違う）は、完了にせず、例外カードで「これは終わっていますか？」と聞く。
