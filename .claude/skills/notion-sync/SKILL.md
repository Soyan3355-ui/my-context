# /notion-sync

Claude Code で進んだ作業を Notion に取り残さないための同期手順。

## 手順

1. **今回のセッションの要点をまとめる**（3〜8行）
   決まったこと・新しく出たタスク・完了したタスク・数字や日付の変更。会話だけで決まったことも含める。

2. **監査**: `notion-auditor` エージェントに、手順1の要点を渡してチェックさせる。

3. **反映**: 監査結果の A・B を `notion-syncer` エージェントに渡して反映させる（同期ログへの記録も syncer が行う）。

4. **リポジトリをコミット**: syncer がファイルを直した場合は、`sync: Notion と同期（YYYY-MM-DD）` の形でコミットし、作業ブランチへ push する。

5. **マーカー更新**: `mkdir -p .claude/state && date +%s > .claude/state/last_notion_sync` を実行する（Stop フックが同期済みと判断するため）。

6. **報告**: そーやんへ短く返す。
   - 直したこと（Notion / リポジトリ）
   - 要確認の質問（あれば、答えやすい選択肢付きで）

## 注意

- セッションの内容が雑談だけで仕事の情報がない場合は、手順2〜4を省略してマーカーだけ更新してよい。
- Notion の既存ページを大きく書き換えたり、削除したりしない。
