## 1. サイトの目的

**講座（畑の寺子屋・米づくり道場）への申込を増やすこと。**

- 最重要の成果指標（コンバージョン）は「講座の申込」とする。
- 補助指標は、講座ページへの到達率、YouTubeからの流入、問い合わせ数とする。

## 2. ターゲット

**農的暮らしに憧れる人。**

- まだ一歩を踏み出していない人が中心。「初心者でも大丈夫」と思える安心材料を重視する。
  - 例: 当日の流れ、参加者の声、よくある質問、持ち物、服装
- 地域は鹿児島（川上地域）を軸にしつつ、YouTube経由の全国の視聴者も想定する。

## 3. トーン＆ムード

**ていねいで落ち着いた暮らし系。ただしワクワク感は大切にする。**

| 方針 | 具体例 |
|---|---|
| 落ち着き | 余白を広めに取る、文字は読みやすく、色数は絞る（土・緑・生成りなどの自然色） |
| ていねい | 写真は暮らしの空気が伝わるものを選ぶ。説明は短く、やさしい言葉で書く |
| ワクワク | 季節の移り変わり、収穫、子どもや参加者の笑顔の写真を効果的に配置する。ページを開いて「やってみたい」と思える見出しを書く |

避けること: 売り込み感の強い表現、派手すぎる装飾、不安をあおる文言。

## 4. 価値観との整合

`values.md` に沿って判断する。

- つながり／本物／育てる／循環を、文章と構成に反映する。
- 「小さな庭師を増やす」という世界観を、読み物の軸にする。
- 義務感や数字だけを追う改善はしない。

## 5. サイト構成（初期案）

1. **トップ**: 世界観の伝わる写真とひと言。すぐ下に講座の申込導線を置く。
2. **講座**: 畑の寺子屋、米づくり道場。日程・場所・費用・対象者・参加者の声・FAQ・申込。
3. **読み物**: 農的暮らしの入口になる記事（SEOの受け皿）。
4. **YouTube導線**: 「畑は小さな大自然」から講座へ進める導線。
5. **橋口農園・プロフィール**: 人柄と取り組みを伝える。
6. **お知らせ**: 講座の募集開始、日程変更など（Notionで管理）。
7. **問い合わせ**: 出張講座・コンサルの依頼窓口。

## 6. 更新と運用の仕組み

| 項目 | 方針 |
|---|---|
| サイト本体 | 静的サイト（Astro想定）＋ Cloudflare Pages |
| お知らせ・講座情報 | Notionのデータベースで管理（そーやん・舞が更新）。項目: タイトル、日付、定員、申込リンク、公開ON/OFF |
| 反映 | Notionを更新後、Claude Codeに依頼して反映する |
| 申込・決済 | 外部サービス（Googleフォーム、Peatix、Stripe等）と連携。導線は1本に絞る |

## 7. SEOの方針

- ドメイン（notefarm.info）は変更しない。
- 旧サイト（Ameba Ownd）のURLから新URLへ**301リダイレクト**を設定する。移行前にURL対応表を作る。
- 各ページにタイトル・説明文・OGPを設定する。講座ページには構造化データ（Event / Course）、農園には LocalBusiness を入れる。
- Googleビジネスプロフィールと連携し、地域検索（鹿児島・川上）を強化する。
- 公開前と四半期ごとに、Claude Codeでメタ情報・リンク切れ・表示速度を点検する。

## 8. 分析と改善のサイクル

- **計測**: GA4 と Search Console を導入する。「講座申込」「問い合わせ」をコンバージョンに設定する。
- **週次**: 数字 → 気づき → 次の一手 を `reports/` にレポートとして出す（Claude Code）。
- **月次**: レポートをもとに、文章・構成・導線の改善を1〜2点に絞って実施する。
- 改善は小さく試し、結果を数字で見る。多すぎる施策を同時に走らせない。

## 9. 移行ステップ

1. 基準書の整理（本書）
2. Ameba Owndの内容棚卸し、新ページ構成と旧URL対応表の作成
3. サイト雛形の制作、Notion連携、デザイン調整
4. GA4 / Search Console の導入、コンバージョン設定
5. ドメイン切り替え、公開、週次レポート開始

移行が完了するまでは、現在のサイトを稼働させ続ける。
