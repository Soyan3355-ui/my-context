# line-to-notion

仕事のLINEのやりとりをNotionに蓄積し、AIが状況を把握できるようにするためのツール（Mac用・第1段階）。

## 目的
LINEで行う仕事のやりとりを、返信漏れや見落としなく把握するため。

## 準備
1. Notionで「インテグレーション」を作り、トークンを取得する（https://www.notion.so/my-integrations）
2. 溜め先にしたいNotionページで、右上「…」→「接続」からそのインテグレーションを追加する
3. `export NOTION_TOKEN=secret_xxx`

## 使い方
1. LINEデスクトップ（Mac）で対象のトークを開き、メニューの「トーク履歴を保存」でtxtを書き出す
2. `python3 main.py dry-run 書き出したファイル.txt` で解析結果を確認する
3. 初回のみ `python3 main.py create-db <親ページID>` でデータベースを作り、表示されたIDを控える
4. `python3 main.py sync 書き出したファイル.txt <データベースID>` で取り込む

同じファイルを再度取り込んでも、送信済みのメッセージは重複しない（状態は `~/.line_to_notion_state.json`）。

## 今後の段階
- 第2段階：LINEの画面を自動スクロールしてスクリーンショットを取り、Claudeの画像読み取りで文字起こしする。
- 第3段階：Notionに溜まった内容から、未返信・期限のあるものを抽出して通知する。

## 注意
- 対象は仕事のグループ・個別トークに限定し、取り込むことを相手にも伝えておく。
- 第1段階はLINE標準の書き出し機能のみを使うため、規約上のリスクは小さい。
